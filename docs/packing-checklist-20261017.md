## Хранение и обновление

Ключ primserv.arrival.packing.v1: version1, публичные английские пункты списков
в исходном порядке и boolean-массивы отметок. Нет имён, дат, города, контактов,
текста URL, кандидатов или свободного ввода. Запись происходит только при
изменении checkbox; открытие/смена города сами по себе не создают запись.
Снять checkbox — убрать свою отметку; массового удаления/очистки нет.

Загрузка валидирует версию, точные поля, состав/порядок пунктов и boolean.
Corrupt/future/неизвестные поля/изменённый список не перезаписываются, показаны
новые отметки только в памяти и предупреждение. Отказ чтения или записи
не блокирует страницу. При несовпадении сохранения перед записью (другая
вкладка/новая версия) запись прекращается; чужая версия остаётся нетронутой.
Закройте лишнюю вкладку и перезагрузите для повторного чтения сохранённого
состояния. Повреждённые/будущие данные автоматически не удаляются: нужна
совместимая версия или осознанное управление конкретной записью пользователем.
Перезагрузка при denied storage теряет только несохранённые отметки.
Старый ключ языка и остальные данные не мигрируются и не удаляются.

## Запуск / офлайн / размер

Локально из корня checkout: python3 -m http.server 8080 --bind 127.0.0.1,
затем http://127.0.0.1:8080/?lang=uk&location=ryczywol . Остановка Ctrl+C.
Команда документирована, но в этой среде ещё не подтверждена браузером.
Первое скачивание/посещение действующего PWA требует сети. Ранее успешно
загруженный и закэшированный shell может работать без сети; на никогда
не открывавшем страницу устройстве это не обещается. SW на file:// не работает.
Карты, внешние ссылки, звонки/мессенджеры требуют соответствующих подключений;
они не запускаются тестами. Чек-лист не делает запросов и не отправляет очередь.

Runtime: app.js +4702 B, styles.css +483 B, index.html +18 B, sw.js +2 B;
итого +5205 B без сжатия. Новых ресурсов/обязательных запросов нет, список
precache не меняется. Корень и index.html могут дублировать HTML в старом cache,
поэтому изменение объёма cache не равно точно 5205 B. Реальный трафик/объём
браузерного cache не измерен. Cache/version v54-housing-contact →
v55-packing-checklist; политика SW не переписана, тяжёлые медиа не добавлены.
